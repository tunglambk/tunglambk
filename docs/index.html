rclone Personal Backup

This is a private-use Google Drive integration configured by its owner for rclone, an open-source file transfer tool.

Its sole purpose is to run scheduled backups of the owner's files to the owner's Google Drive account. It is not offered as a service to the public.

How access works

  • Google OAuth is used to authorize rclone to access Google Drive.
  • The integration is intended to use the drive.file permission, limited to files created or specifically made accessible to the application.
  • Backup files are stored in the owner's Google Drive account, not on this website.
