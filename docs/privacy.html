rclone Personal Backup

Privacy Policy

This policy describes how the owner's personal rclone Google Drive integration uses Google user data. This integration is for the owner's use only and is not distributed as a public application.

Data accessed and purpose

With the owner's authorization, rclone accesses Google Drive files within the permission granted to the integration to create, list, download, update, and delete backup files as required by the owner's configured backup tasks. The intended permission is drive.file.

Data storage

Backup files are uploaded directly between the owner's computer or server and the owner's Google Drive account. OAuth tokens and rclone configuration are stored on the owner's own device or server. This static website does not receive backup files, passwords, or OAuth tokens.

Sharing and use

Google Drive data is used only to perform the owner's backup operations. The owner does not sell Google user data, use it for advertising, or intentionally disclose it to unrelated third parties. Data is necessarily transmitted to Google's Drive service to store and retrieve backups.

Retention and deletion

The owner controls how long backup files are retained and can delete them through rclone or Google Drive. OAuth access can be revoked in the Google Account's security settings; local credentials can be removed from the rclone configuration.

Changes

This page may be updated if the integration or its data practices change. Last updated: October 9, 2026.
